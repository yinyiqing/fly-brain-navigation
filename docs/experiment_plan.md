# 课程作业范围：单体归巢与运动噪声

暂定题目：**运动噪声对数字果蝇归巢误差的影响**。

用户明确本项目只是一门课的作业，可投入时间有限。12 月是截止月份，不代表可以持续投入一个月。以一个完整、可解释、可复现的小实验为目标，完成以下交付后收尾。

## 初始必做范围

- 一个二维场景，一只果蝇，一条固定的短外出路线，随后估计并返回起点。
- 使用已准备的 FlyWire v783 和 Brian2 模型；普通几何路径积分作为参照。神经模型实际承担的作用必须在实现和报告中写清楚。
- 只研究一个变量：方向观测噪声。先设无、低、高三档，各重复三个固定随机种子，保留逐次结果。此规模用于课程示例，不据此作广泛的统计结论。
- 两张主要结果图：代表性外出/返程轨迹，以及噪声强度与归巢误差的关系。附一张小型结果表。
- 一份可直接运行的实验脚本、简短运行说明和任务书要求的 3–5 页报告。

## 实现顺序和停止条件

1. 先完成二维运动、几何路径积分和误差计算，固定路线、噪声生成方式、停止阈值和超时条件。真实位置用于生成带噪声观测和评价，不直接输入归巢控制器。
2. 做一次规模受限的神经输入/读出原型，检查神经活动能否提供方向信息。外部算法若承担位置累积，要明确说明，不能称作连接组自主实现了路径积分。
3. 原型可用后运行上述小实验，并在一个噪声条件下加入关闭或打乱神经读出的对照，检查神经模块是否影响行为。
4. 若首轮神经接口检查无效，记录现象、检查一次实现，再确定是否能以负结果完成课程要求；不连续扩展模型或无限调参来追求成功率。基础仿真产生放电不等于归巢能力成立。
5. 图表、代码和报告齐全后结束，不自动追加扩展项目。

## 2026 年 11 月 4 日有界改进结果

原实现无噪声失败种子的终点误差主要来自返程方向读数，而不是外出位置估计。把单次神经观察窗口延长至 1,000 ms 后，无噪声的原始种子成功率仍为 1/3；三个新种子上 250 ms 和 1,000 ms 的无噪声成功率都为 2/3，故不采纳较长窗口。

随后在外部控制器增加无可调参数的因果圆周平均：将历史神经方向按实测转向补偿到当前朝向后与当前读数合并。原有三个种子中，无噪声平均误差从 2.04 降至 0.19，成功率从 1/3 提升至 3/3；新种子 401、402、403 的无噪声条件也达到 3/3。5° 和 15° 下结果没有稳定改善。

检查表明这是一项针对神经读出波动的外部时间平均，不是数字果蝇脑内的跨步记忆。转向噪声仍在累积，神经网络每个窗口仍从静息状态开始。代码、单元测试、固定配置、逐次结果、两组独立种子和进程复跑均已保存。以上是阶段结果，后续仍以小规模归巢改进为主，最终报告待实验方案和结果稳定后整理。
