# 运动补偿后的神经方向平均

2026 年 11 月 4 日，长窗口实验结束后、运行本方法前固定本计划。

第一项改动把观察窗口从 250 ms 延长至 1,000 ms。原种子的无噪声平均终点误差从 2.04 降为 1.74，但成功次数仍为 1/3；复核种子成功次数仍为 2/3，有噪声结果没有稳定改善。因此不采用长窗口作为默认改进，其完整结果保留。

根据此前对最后一次方向读出误差的诊断，本轮再尝试一次不带可调参数的外部处理：保留 250 ms 窗口，将历史神经方向读数按已观测到的转向增量转到当前时刻，再求圆周平均。每一步只使用当前和过去的神经读数与转向观测，不使用真实位置、真实方向、未来观测或路线分段信息。

用复数表示方向，递推为 Z_t = exp(i·Δθ_obs,t)·Z_(t-1) + exp(i·θ_neural,t)，Z_0 = 0；处理后方向为 arg(Z_t)。精确相消时退回当前神经读数。该方向用于外部位置积分和返程相对转向。这是外部算法的时间平均，不是神经环路记忆，也不会消除原转向观测自身的累积漂移。
