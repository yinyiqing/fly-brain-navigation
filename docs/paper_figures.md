# 论文插图与图注

图 1 已放入最终论文。图 2–4 是补充实验图，可按论文篇幅选择使用。全部提供 PNG 和矢量 PDF；Word 可直接插入 PNG，LaTeX 可使用 PDF。图 1 的 PNG 为 400 dpi，建议以约 14.65 cm 宽插入，保持纵横比。

## 图 1 出发 返程与搜索

先看左图的成功案例，按 A → B → C → 终点阅读：

- A 是家，也是出发点。蓝色虚线表示从 A 到 B 的外出路线。
- B 是外出结束的位置，从这里开始回家。橙色实线表示依据估计位置执行的直接返程。
- C 是直接返程结束、尚未到家时开始搜索的位置。紫色点划线表示后续局部搜索。
- 箭头指向实际运动方向；绿色圆点是成功终点，红色叉号是失败终点。
- 家周围的浅色圆是成功区域，半径为 1。场地没有障碍物；绕方形表示搜索，不表示避障。

左图为 5° 观测噪声，右图为 15° 观测噪声；两图使用同一预定原路线、种子 701、2° 返程转向执行误差和搜索预算 72，坐标范围与比例相同。B、C 来自保存轨迹的真实阶段边界，没有手工移动轨迹、改变结果或筛选种子。图中的真实位置标记用于读者理解，不是传给导航控制器的信息。

**可用图注：** 固定种子 701 的归巢轨迹。A 为家与出发点，B 为开始返程位置，C 为开始搜索位置。蓝虚线、橙实线与紫点划线分别表示外出、直接返程和局部搜索，箭头指示运动方向。浅色圆为半径 1 的成功区域，环境无障碍物。两图均含 2° 返程转向执行误差；5° 观测噪声案例最终到达，15° 案例在搜索预算耗尽后失败。

## 图 2 神经方向对照

**可用图注：** 正常读出、五组方向标签置换与关闭读出的对照。标签置换增大了未见方向的解码误差，并降低旧种子、5° 观测噪声条件下的归巢效果。五组置换共享同一批神经特征和导航试验，不视为额外独立样本；该对照不检验真实连接组相对随机连接组的优势。

## 图 3 返程执行误差

**可用图注：** 三条路线、十个新种子下的到达次数与平均返程路程。比较理想返程和每次转向叠加 2° 标准差执行误差的条件；每档观测噪声含 30 个路线与种子组合，搜索预算 72。路程均值包括失败试验，路线之间共享随机种子。

## 图 4 搜索预算与代价

**可用图注：** 搜索预算 0、18、36、72 下的归巢成功率与实际返程路程。各条件共用预定路线、种子及配对执行误差。增大预算可补救部分失败，但增加移动代价，无法保证每次到达。

## 重画图 1

在项目根目录、具有 matplotlib、NumPy、pandas 和中文字体的环境运行：

```bash
python scripts/plot_paper_trajectory.py
```

脚本优先使用便于嵌入 PDF 的 TrueType 中文字体（当前服务器为 Droid Sans Fallback），也支持 Noto Sans CJK；已有 Linux 仿真环境可直接运行。输入是 `examples/validation-20261104/demo_trajectories.csv` 与对应指标；输出是 `reports/assets/paper_trajectory.png` 和同名 PDF。绘图时核对阶段衔接、路程及成功状态，无需重新运行 Brian2。
