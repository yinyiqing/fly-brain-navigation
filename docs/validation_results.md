# 神经方向信息与返程误差验证结果

本轮完成方向标签对照、新种子返程误差验证和搜索预算分析。新增 90 个神经导航试验，使用三条路线和十个新种子；运行前固定的配置与方案见 `configs/homing_validation.json`、`docs/validation_plan.md`。

## 主要结果

正常神经读出的未见方向平均误差为 4.24°，五组方向标签打乱后为 65.29°–111.94°。标签打乱后的归巢效果和行走代价也变差，支持当前流程确实依赖正确的方向对应关系。

新种子中，神经运动平均加有限搜索在无噪声和 5° 外出观测噪声下均到达 30/30；对每条返程转向指令加入 2° 标准差的执行误差后，仍均为 30/30。15° 高观测噪声下，理想返程为 21/30，加入执行误差后为 20/30。所有失败保留。

搜索预算 36 在旧样本中能覆盖低噪声全部成功，但在新样本中只能到达 27/30 或 28/30。因此保留原 72 预算作为主配置，不把旧样本上的较省预算直接当成稳定结论。

## 方向标签对照

使用旧的 601–605 种子结果，复用同一批放电计数。将 16 个训练方向作固定置换，同方向的三次训练样本仍共享一个标签；训练数量、神经特征、岭回归参数和运动平均不变。未见方向不用于训练，测试过程没有打乱时间序列。

| 读出条件 | 未见方向平均误差 | 5° 噪声、搜索预算 72 到达次数 | 平均返程路程 |
| --- | ---: | ---: | ---: |
| 正常神经读出 | 4.24° | 15/15 | 15.06 |
| 标签置换 801 | 104.32° | 3/15 | 71.14 |
| 标签置换 802 | 111.94° | 10/15 | 54.52 |
| 标签置换 803 | 81.11° | 7/15 | 52.20 |
| 标签置换 804 | 65.29° | 13/15 | 38.05 |
| 标签置换 805 | 104.46° | 8/15 | 54.90 |
| 关闭读出 | 90.00° | 6/15 | 68.99 |

几何积分加相同搜索为 15/15，平均返程路程 15.12。五个置换是同一批数据上的五个对照，不能合并成 75 个独立导航试验。置换 804 仍达到 13/15，说明后续搜索能补救部分错误读出；不能只看最终成功率，还需看神经解码误差和多走的路程。

该结果支持“正确训练的神经方向接口对当前流程有用”。它不证明真实连接组优于随机网络，也不证明脑内路径积分。方向和位置累积仍由外部代码承担。

## 新种子与返程执行误差

三条路线均长 18，种子为 701–710，每个噪声条件包含 30 个路线与种子组合。跨路线共用十个种子，不能把 30 个组合当作 30 个独立随机种子。所有方法和预算共用按动作序号对齐的执行误差序列。

以下为神经归巢加搜索，预算固定为 72。路程均值包含失败试验。

| 外出观测噪声 | 理想返程到达次数 | 2° 返程转向误差到达次数 | 理想 / 有误差平均返程路程 |
| --- | ---: | ---: | ---: |
| 0° | 30/30 | 30/30 | 8.62 / 8.64 |
| 5° | 30/30 | 30/30 | 19.14 / 18.36 |
| 15° | 21/30 | 20/30 | 45.58 / 46.76 |

在 15° 条件，加入执行误差后有一例由成功变为失败，没有由失败变为成功的例子。5° 下平均路程略缩短，是这批随机扰动让部分轨迹更早接触目标的结果，不能解读为“执行噪声有益”。

几何方法在 0°/5°/15° 条件的理想返程成功次数分别为 30/30、29/30、21/30；加入 2° 执行误差后为 30/30、30/30、20/30。当前小样本不支持神经方法优于几何方法。

## 搜索预算与行走代价

旧结果的预算分析在 `budget_historical.csv` 中明确标为回顾性分析。下面只列新种子的验证结果。

| 额外搜索预算 | 5° 理想 / 有误差到达次数 | 15° 理想 / 有误差到达次数 |
| --- | ---: | ---: |
| 0 | 11/30 / 12/30 | 5/30 / 5/30 |
| 18 | 24/30 / 24/30 | 11/30 / 11/30 |
| 36 | 27/30 / 28/30 | 15/30 / 15/30 |
| 72 | 30/30 / 30/30 | 21/30 / 20/30 |

15° 观测噪声和 2° 执行误差下，预算从 36 增到 72，成功次数从 15 增到 20，平均返程路程从 31.69 增到 46.76。低噪声下同样增加预算，成功次数从 28 增到 30，平均路程从 18.04 增到 18.36，因为大多数试验会提前到达，不会走满预算。

本轮保留 72 为主配置。成功半径保持 1，未根据新结果追加预算、挑选种子或改变到达判定。

## 复现与开销

新神经试验加控制器分析约 106.77 秒，不含绘图；单个神经进程的峰值 RSS 约 611.72 MiB，三条路线顺序执行，使用 CPU。无新增模型训练框架和数据下载，仅重新拟合轻量读出及运行既有 Brian2 模型。

本地和服务器通过 20 项单元检查。另起进程，从保存的放电计数和返程指令重算 10 张数据表，720 行方向对照、1,440 行返程验证及演示轨迹在 1e-10 容差内一致。正常读出、几何方法和关闭读出在旧条件下与旧结果一致。此处的重放不包含再次运行神经模型。

`raw/` 保留每条新路线的配置、神经计数、读出权重、轨迹和环境记录；可重新生成的连接组数据副本未加入 Git。演示使用运行前固定的原路线、种子 701、2° 返程转向误差。

仍存在的限制包括：人工方向输入、神经窗口重置、外部积分与搜索、准确距离、理想到达检测、没有障碍，以及少量固定路线。当前结果适用于这个课程规模的仿真设置，不代表真实果蝇或真实机器人已获得同样能力。
