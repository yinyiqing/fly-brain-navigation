# 果蝇方向读出与归巢成果包

先打开 `01_论文/果蝇连接组方向读出与归巢验证_24025110_尹一清.docx`。正文依次说明方向怎样输入网络、读出器怎样学习，以及预测方向怎样用于返回起点。

| 位置 | 内容 |
| --- | --- |
| `01_论文` | 一份最新版 Word 论文，沿用指定参考报告的排版 |
| `02_论文插图` | 正文图一与补图 S1–S4，提供高清 PNG、矢量 PDF 和图注 |
| `03_补充材料` | 输入公式、实现参数、完整实验比较，以及版本和文件校验记录 |
| `04_代码与数据.zip` | 代码、配置、依赖清单和实验记录；解压后生成“代码与数据”文件夹 |

查看归巢过程时，打开补图 S1：蓝色为外出，橙色为直接返程，紫色为附近搜索。A 是起点，B 开始返程，C 开始搜索。场地没有障碍物。

论文集中在 `01_论文`，代码包不再重复放入报告。旧动画和早期报告已从成果包移除，逐次实验数据保存在代码包的 `examples/` 中。

如需核对数据或重新运行实验，解压代码包后按其中的 `README.md` 操作。可以先用保存的神经输出核对导航结果，无需 GPU 或重新运行神经仿真。

项目与提交记录：[yinyiqing/fly-brain-navigation](https://github.com/yinyiqing/fly-brain-navigation)。
