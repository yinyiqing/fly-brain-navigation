# 归巢加有限搜索：阶段结果

本轮目标是在三条路线、五个新种子的验证中实际进入起点区域。0° 和 5° 条件均到达 15/15，达到运行前约定的目标；15° 条件到达 10/15，仍有失败。

## 实际做了什么

保留 FlyWire CX 神经方向读出、运动补偿圆周平均和外部路径积分。完成原来的返程指令后，若未到达起点区域，则执行外部扩展方形搜索。间隔固定为 1.5，附加路程上限固定为 72；没有根据这轮结果重新调参。

新增任务假设是：进入起点半径 1 的区域时，可以确认到达并停止。这个信号只用于终止，不包含方位、距离或坐标；实际系统需要接触或局部识别。直接返程与搜索使用相同的首次接触终止规则。真实位置只参与环境执行和评价，不传给生成返程动作的函数。

这不是没有任何外界确认的纯盲归巢，也不是连接组自主学会搜索。返程沿用理想执行条件，没有新执行噪声和障碍物。

## 结果

三条外出路线均长 18，分别为原路线、另一条折线和连续缓弯。种子为 601–605，各路线共用这五组随机种子，便于配对比较；不能把它们当作十五组独立随机种子。每档噪声包含 15 次路线与种子的组合。

| 方法 | 0° 到达次数 | 5° 到达次数 | 15° 到达次数 |
| --- | ---: | ---: | ---: |
| 神经直接返程 | 15/15 | 3/15 | 1/15 |
| 神经返程加搜索 | 15/15 | 15/15 | 10/15 |
| 几何直接返程 | 15/15 | 3/15 | 0/15 |
| 几何返程加搜索 | 15/15 | 15/15 | 9/15 |

| 噪声 | 神经直接返程平均路程 | 神经返程加搜索平均路程 | 其中平均搜索路程 |
| --- | ---: | ---: | ---: |
| 0° | 8.61 | 8.61 | 0.00 |
| 5° | 8.78 | 15.06 | 6.28 |
| 15° | 7.72 | 48.89 | 41.17 |

路程均值包括失败试验，是相同试验组合下的实际行走代价。5° 下原路线、折线和缓弯路线分别成功 5/5；15° 下分别为 3/5、4/5、3/5。高噪声失败保留，不通过放宽目标区域或增加搜索预算改成成功。

5° 条件关闭神经读出后，即使保留相同搜索，也只到达 6/15，平均返程路程 68.99。这说明正常神经读出的初始归巢指令对当前流程有用。几何积分加搜索同样达到 15/15，说明主要收益来自搜索，不能证明真实连接组优于几何方法或随机网络。

成功试验在首次接触半径 1 的区域边界时停止，所以停止后的误差约为 1。这与旧实验“把直线走完后计算终点误差”的口径不同，不能拿两个平均误差直接比较。`metrics.csv` 的 `initial_endpoint_error` 保留旧口径；本轮两种方法均按相同的首次到达规则比较。

## 验证和复现

- 本地和服务器各通过 14 项单元检查。
- 原神经仿真脚本与上一版完全一致；三次标定的未见方向平均误差仍为 4.24°。
- 三路线神经试验顺序执行，约 60.53 秒，不含出图；使用 CPU，无新增训练或数据下载。
- 另起进程，使用已保存的神经返程指令重放导航，210 行方法结果、16,975 行轨迹在 1e-12 容差内一致。这次复核不包含重新运行神经模型；此前版本已有神经仿真的独立进程复跑记录。
- 逐次结果、分路线统计、原始神经读出记录、固定示例图和验证记录位于 `examples/search-20261104/`。

本轮只支持“在这些路线、种子和理想返程条件下，有限搜索提高到达率”。后续若需要进一步提高可信度，重点应放在到达信号和返程执行误差，而不是直接扩大模型或追求更多报告页数。
