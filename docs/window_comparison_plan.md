# 神经观察窗口的单项改进

2026 年 11 月 4 日，在运行新配置前固定本计划。用户选择先小幅改进归巢效果。

原实验中，无噪声的种子 21 和 42 最后一次神经方向读出分别偏差约 -10.81° 和 15.92°，终点误差为 2.19 和 3.50；外出阶段的位置估计误差只有 0.23 和 0.36。诊断提示返程转向对最后一次读出误差敏感。真值仅用于离线诊断，不输入控制器。

只把观察窗口从 250 ms 延长至 1,000 ms，使用相应窗口重新标定读出。假设是较长时间的脉冲计数有助于减少 Poisson 采样波动。模型、路线、输入率、训练方向、训练样本数、岭回归系数和成功阈值均保持不变。该改动会增加模拟观察时间与计算耗时，不代表消除传感器漂移。

- 主比较使用原种子 7、21、42，三档噪声仍为 0°、5°、15°。
- 新种子 101、202、303 用于复核，两种窗口都运行完整三档噪声；不根据结果更换种子。
- 重点评价无观测噪声时的平均终点误差和成功次数，同时完整报告两档有噪声结果及独立方向测试误差。
- 本轮只尝试 1,000 ms 这一项配置，不按导航结果搜索窗口、读出参数或种子。
- 新配置另起进程复跑一次，核对数值输出；原实验及报告保留。

即使效果改善，方向与位置仍由外部程序累积，神经网络每个窗口均重置。结论仅限于本任务的读出精度与归巢误差，不表述为连接组自主路径积分。
