# 方向读出论文补充材料

正文按方向输入、放电记录、读出训练和归巢控制说明方法。本文件集中列出实现参数、各实验的论证职责和结果索引，并保留观察窗口与运动补偿平均的完整比较。

## 方法实现参数

正文先说明一条数据如何经过整个流程，具体版本、筛选规则与配对设置集中在下表。以下设置来自现有代码和保存配置。

| 环节 | 设置与规则 |
| --- | --- |
| 数据和网络 | FAFB / FlyWire v783 连接数据与 v2.1.0 细胞注释；2,869 个 CX 神经元，300,065 条内部连接记录 |
| 放电仿真 | Brian2 2.5.1，步长 0.1 ms；沿用公开模型的带符号连接权重与泄漏积分发放（LIF）方程，神经元达到阈值后放电并复位 |
| 方向刺激 | 47 个 EPG 输入神经元按原始行序均匀分配人工偏好角；Poisson 刺激频率为 15–150 Hz；每次运行 250 ms，运行前恢复静息状态 |
| 放电特征 | 按来自 EPG 的连接绝对权重之和降序选择 128 个非输入神经元；权重相同则按索引排序，在观察训练响应之前完成选择 |
| 标准化 | 各维放电次数减去训练均值，再除以训练标准差与 1 的较大值；测试及归巢沿用训练集统计量 |
| 训练目标 | 16 个方向、间隔 22.5°，各重复三次，共 48 个样本；岭回归预测方向的余弦和正弦，正则系数为 10，偏置为训练目标均值 |
| 独立方向测试 | 相邻训练方向中点，共 16 个，每个方向使用一次新随机种子的响应；测试角度与最近训练方向相差 11.25° |
| 标签对照 | 种子 801–805 生成五组标签置换；保持特征、拟合设置与数据不变，同方向的三次样本使用相同置换标签 |
| 外出路线 | 原折线、往复折线和渐变转向三条路线，总长均为 18；完整方向与距离序列保存在实验输入配置中 |
| 旧导航种子 | 601–605，用于标签与搜索对照；三条路线，每档 15 个路线与种子组合 |
| 新导航种子 | 701–710，用于多路线与执行误差验证；三条路线，每档 30 个组合 |
| 配对比较 | 路线之间共享导航种子；神经方法与几何基线使用相同运动观测、搜索和到达规则，返程执行误差按动作序号对齐 |

实现见 `scripts/run_homing.py`、`scripts/run_search_homing.py` 和 `scripts/run_validation_suite.py`；主配置见 `configs/homing_motion_average.json`、`configs/homing_search.json` 和 `configs/homing_validation.json`。方向误差评价恢复输入角度的准确程度，运动中的转向观测误差由导航实验另行设置。

## 返程路程差异的计算

在 5° 观测噪声、搜索预算 72、种子 601–605 与三条路线的对照中，正常读出的平均返程路程为 15.05990044。五组标签置换的平均返程路程分别为 71.14273271、54.51795879、52.19841855、38.04522656 和 54.90060823。

相对路程减少比例按 `1 - 正常读出平均路程 / 置换组平均路程` 计算。以路程最短的置换组 804 为参照，比例为 60.4158%，正文保留一位小数，写为“较五组置换至少缩短 60.4%”。该比例比较五个标签置换条件；几何基线另按相同运动观测下的任务表现分析。

## 观察窗口比较

比较 250 ms 与 1,000 ms 的神经响应窗口。两种设置使用同一条折线路线和配对运动观测，分别拟合读出器；每组种子在每档噪声下有三个试验。此处评价直接返程结束时的终点误差，以及终点是否位于起点半径 1 的区域内。

| 种子组 | 观测噪声 | 平均终点误差 250 / 1,000 ms | 成功次数 250 / 1,000 ms |
| --- | ---: | ---: | ---: |
| 7、21、42 | 0° | 2.04 / 1.74 | 1/3 / 1/3 |
| 7、21、42 | 5° | 2.39 / 2.47 | 1/3 / 0/3 |
| 7、21、42 | 15° | 6.88 / 8.83 | 0/3 / 0/3 |
| 101、202、303 | 0° | 1.41 / 0.77 | 2/3 / 2/3 |
| 101、202、303 | 5° | 1.04 / 1.85 | 2/3 / 0/3 |
| 101、202、303 | 15° | 4.74 / 5.45 | 0/3 / 0/3 |

1,000 ms 窗口的未见方向平均误差为 3.80°，250 ms 为 4.24°。两组导航种子共用相同的标定与方向测试随机种子。延长窗口改善了方向标定误差，但带噪声归巢的终点误差未随之稳定下降；正文采用 250 ms 配置。

数据来源：`examples/window-comparison-20261104/window_comparison.csv` 与 `comparison.json`。

## 运动补偿平均比较

使用 250 ms 响应窗口，将历次方向读数按观测转向旋转到当前朝向，再作圆周平均。路线、直接返程终点指标和成功半径与上述比较一致。

| 种子组 | 观测噪声 | 平均终点误差 原始读出 / 运动平均 | 成功次数 原始读出 / 运动平均 |
| --- | ---: | ---: | ---: |
| 7、21、42 | 0° | 2.04 / 0.19 | 1/3 / 3/3 |
| 7、21、42 | 5° | 2.39 / 2.92 | 1/3 / 0/3 |
| 7、21、42 | 15° | 6.88 / 8.26 | 0/3 / 0/3 |
| 401、402、403 | 0° | 1.05 / 0.35 | 1/3 / 3/3 |
| 401、402、403 | 5° | 2.10 / 1.28 | 0/3 / 0/3 |
| 401、402、403 | 15° | 3.93 / 3.94 | 0/3 / 0/3 |

两组种子在无观测噪声时均由 1/3 增至 3/3。带噪声条件下，平均终点误差的变化随种子组而异：5° 时分别为 2.39 → 2.92 和 2.10 → 1.28。这项比较用于说明运动平均的响应特征；正文归巢结果采用运动平均加有限搜索的配置，并同时报告到达次数和路程。

数据来源：`examples/motion-average-20261104/summary.csv`、`examples/motion-confirm-20261104/summary.csv`。两组设置及随机种子分别保存在各目录的 `config.json`。

## 指标与复现

方向误差以人工输入方向为参照。窗口和运动平均比较统计直接返程结束时的终点，正文搜索实验则在首次进入起点区域时停止，二者的成功判定时刻各按所属实验定义。

正文的标签置换共用同一批放电数据，多路线验证在三条路线间共用十个导航随机种子，样本量以路线与种子组合报告。完整配置、逐次记录和保存的神经输出均随项目提供；复现入口见 `README.md` 和 `docs/final_delivery.md`。
