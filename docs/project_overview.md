# 项目总览

本项目以方向编码与读出为核心：把已知方向编码成刺激，经过固定的果蝇连接组网络，再用下游放电训练外部岭回归读出器，检验未见方向的恢复误差。归巢是这些方向读数的应用验证。训练目标是恢复输入方向，网络连接与权重保持固定。

## 方法分工

```mermaid
flowchart LR
    A[运动观测：带噪声转向与准确距离] --> B[外部程序累积方向]
    B --> C[人工 EPG 方向输入]
    C --> D[FlyWire CX 脉冲神经网络]
    D --> E[下游放电计数与外部岭回归读出]
    E --> F[外部运动补偿平均与位置积分]
    A --> F
    F --> G[估计返程指令]
    G --> H[环境执行返程与有限搜索]
    H --> I[进入起点区域则停止]
```

神经网络使用 2,869 个 CX 神经元和 300,065 条连接记录，人工刺激 47 个 EPG 神经元，读取 128 个非输入神经元。每个 250 ms 窗口从静息状态开始；神经网络没有跨步记忆。方向累积、位置积分、时间平均、搜索以及动作选择均由外部代码承担。真实位姿只用于环境执行与评价。

训练的是“放电特征到输入方向”的映射：48 个样本训练，16 个未见方向测试，平均角误差 4.24°。五组方向标签置换后为 65.29°–111.94°。这一指标评价输入方向的恢复精度；归巢阶段再考察叠加运动观测误差后的效果，并通过搜索预算比较到达次数和路程。

## 阅读和运行顺序

先读仓库 README 与 `docs/validation_results.md`，查看 `reports/assets/paper_trajectory.png` 和三张验证图。论文轨迹图标明外出、返程、搜索的阶段及方向，并提供矢量 PDF；固定使用原路线和种子 701，不通过挑选试验美化效果。

最终论文为 `reports/果蝇连接组方向读出与归巢验证_24025110_尹一清.docx`，沿用用户指定参考格式，共 5 页。方法部分展开了刺激编码、放电特征、训练样本、岭回归目标及圆周角度读出；分析部分解释标签对照与归巢误差。正文以两张表汇总结果，完整置换明细和四张静态图作为补充材料。此前报告保留。用 `scripts/package_delivery.py --output ../最终成果` 可导出完整成果包，具体说明见 `docs/final_delivery.md`。

完整仿真在 Linux、Python 3.10 和固定依赖环境中运行。服务器中已有数据和环境，README 提供命令。仅检查导航与重放结果时，无需 Brian2、大数据下载或显卡，只需 NumPy 和 pandas。GitHub Actions 会运行单元检查、旧结果导航重放和最新十张验证表核对；它不执行完整神经仿真。

## 项目边界和结题剩余事项

- 本项目是连接组神经读出参与导航，不是果蝇脑自主完成路径积分。标签打乱对照不等于随机连接组对照。
- 最新返程实验只对转向加入执行误差，行走距离、二值到达检测仍理想，没有障碍物。
- 三条路线共享同一组随机种子，不能把路线与种子组合全部视为独立随机样本。标签置换同样是共享数据的对照，不增加独立样本量。
- 高噪声失败以及未采用的长窗口方法均保留，报告需与这些实际结果一致。
- 最终论文已按指定排版整理为任务书要求的 5 页学术小论文；旧 Word 报告作为阶段记录保留。
- 需由课程交流确认选题不与同学重复，并核对老师指定的公共底座与当前 Shiu 公开模型是否一致；目前没有这两项的确认材料。
